# P1-Analise-Viabilidade

Repositório destinado ao desenvolvimento, documentação e versionamento do Projeto P1 – Análise de Viabilidade para um Caso Real, integrante da capacitação em Sistemas Agentes da SOFTEX.

O repositório será utilizado para organizar a análise técnica, os estudos de viabilidade, os testes e os demais artefatos necessários à execução do projeto.

Comprometo-me a manter o repositório atualizado durante o desenvolvimento das atividades, visando à entrega final no Laboratório de Avaliação e à avaliação por pares.
